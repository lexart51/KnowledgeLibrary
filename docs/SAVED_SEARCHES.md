# Saved Searches

This describes saved searches available in the stable 6.4.1 production baseline.


KnowledgeLibrary 6.4.0 can store optional saved searches in plugin data.

Saved searches contain:

- name
- query
- display mode
- sort mode
- created and updated timestamps

Commands:

- `Knowledge Library: Save current search`
- `Knowledge Library: Manage saved searches`

Saved searches do not modify vault notes and are not written to connected external vaults.
