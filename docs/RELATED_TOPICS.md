# Related Topics

Related Topics are calculated from co-occurring discovered topics on the same logical items. For example, a Hermes item tagged with OpenRouter, Claude, Agents, MCP, DeepSeek, or NotebookLM can cause those topics to appear as related to Hermes.

The calculation uses existing metadata only. It performs no AI processing, network calls, summarization, or external vault writes.

The Topic settings section controls the visible related-topic depth.
