# Diagnostics

KnowledgeLibrary 6.4.1 adds a Diagnostics view and self diagnostics command.

Diagnostics show:

- plugin version
- state schema version
- build version
- current vault
- connector count
- available and unavailable connectors
- unified index status
- indexed item count
- last rebuild
- cache status
- plugin data path
- Obsidian version
- operating system

Use `Knowledge Library: Open diagnostics` to view diagnostics and copy the report.

Use `Knowledge Library: Run self diagnostics` to verify that state, connectors, index, saved searches, diagnostics writes, and plugin-data permissions are working.
